DOOM FOR TANDY 1000, CGA AND VGA - DOS AUTOMATIC VIDEO

Run DOOM at the DOS prompt. It detects VGA, then native
Tandy graphics, otherwise chooses the 4-color CGA driver.

COMMAND LINE:
  DOOM                  Automatically choose video
  DOOM -detect          Show what the machine reports
  DOOM -tandy           Tandy 160x200 full screen, 16 RGBI colors
  DOOM -tandyhi         Tandy 16-color higher-detail 3D
  DOOM -cga             CGA 4-color mode
  DOOM -vga             VGA 256-color mode 13h
  DOOM -video tandy     Alternative override form
  DOOM -video auto      Reset video to automatic
  DOOM -help            List available options

On the Tandy 1000 EX run DOOM or DOOM -tandy. If
DOOM -detect incorrectly reports CGA, force -tandy.

Keep DOOM.EXE, the four .OVL renderer files, and their
corresponding WADs TOGETHER in the same DOS directory:
  DOOMTGA.OVL / DOOMTGH.OVL --> DOOMT16.WAD
  DOOMCGA.OVL                --> DOOM4.WAD
  DOOMVGA.OVL                --> DOOM1.WAD

Only DOOM.EXE should be launched. The other .OVL files
are full 16-bit DOS engines loaded by the DOS EXEC
function so the tiny launcher does not occupy game RAM.
No direct DOOMTGA.EXE or DOOMVGA.EXE is required.

All ordinary game arguments are forwarded:
  DOOM -tandy -timedemo demo3 -quick
  DOOM -vga -noems -noxms -nosound

Use BENCH.BAT to time fast/detail Tandy video on real
hardware. Use Ctrl to fire, arrows to move, Space to
open doors, F10 to exit. 640 KB conventional memory
is recommended.
