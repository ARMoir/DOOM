DOOM FOR TANDY 1000, CGA AND VGA - DOS AUTOMATIC VIDEO

Run DOOM at the DOS prompt. It detects VGA, then native
Tandy graphics, otherwise chooses the 4-color CGA driver.

COMMAND LINE:
  DOOM                  Automatically choose video
  DOOM -detect          Show what the machine reports
  DOOM -tandy           Tandy 160x200 full screen, 16 RGBI colors
  DOOM -tandyhi         Tandy 16-color higher-detail 3D
  DOOM -cga             CGA 4-color mode
  DOOM -vga             VGA 256-color mode 13h
  DOOM -video tandy     Alternative override form
  DOOM -video auto      Reset video to automatic
  DOOM -help            List available options

On the Tandy 1000 EX run DOOM or DOOM -tandy. If
DOOM -detect incorrectly reports CGA, force -tandy.

Keep DOOM.EXE, the four .OVL renderer files, and their
corresponding WADs TOGETHER in the same DOS directory:
  DOOMTGA.OVL / DOOMTGH.OVL --> DOOMT16.WAD
  DOOMCGA.OVL                --> DOOM4.WAD
  DOOMVGA.OVL                --> DOOM1.WAD

Only DOOM.EXE should be launched. The other .OVL files
are full 16-bit DOS engines loaded by the DOS EXEC
function so the tiny launcher does not occupy game RAM.
No direct DOOMTGA.EXE or DOOMVGA.EXE is required.

All ordinary game arguments are forwarded:
  DOOM -tandy -timedemo demo3 -quick
  DOOM -vga -noems -noxms -nosound

Use BENCH.BAT to time fast/detail Tandy video on real
hardware. Use Ctrl to fire, arrows to move, Space to
open doors, F10 to exit. 640 KB conventional memory
is recommended.

Source and license:
https://github.com/ARMoir/DOOM

SOUND (works independently of video adapter):
  DOOM -sound auto     Tandy PSG when Tandy ROM detected, else PC
  DOOM -sound tandy    Force Tandy's 3-tone + noise sound hardware
  DOOM -sound pc       Force traditional one-voice PC speaker
  DOOM -nosound        Silence all effects and music
  DOOM -nosfx          Background music only (on Tandy PSG)
  DOOM -nomusic        Sound effects only

On Tandy: 3 independent tone effects, separate noise bursts and
low-CPU original background music. Effects always replace music
on occupied PSG voices and the melody resumes automatically. The
music is an original hardware demo loop, NOT Bobby Prince's Doom
soundtrack. Non-Tandy PCs default to PC speaker with no music.
Only force Tandy PSG on machines that actually have that hardware.


TITLE SCREEN COLOR FIX:
The Tandy title, help, map, status bar and tiled background now
use clean VGA artwork converted to the Tandy 16-color RGBI palette
offline. DOOMT16.WAD must be replaced along with the new release.
No separate runtime palette or graphics option is needed.


IN-GAME TANDY COLOR FIX:
Replace DOOMT16.WAD and the .OVL game binaries together.
The new WAD eliminates two-color EGA dithering from verified
wall/sprite/UI patch pixels and all COLORMAP lighting levels.
The flat sky constant is now a full 4-bit RGBI nibble pair.
This should eliminate the checkerboard ceiling/floor and
much of the garish vertical wall coloring seen on the EX.
No additional CPU work is required at runtime.

TANDY WALL TEXTURE CORRECTION:
DOOMT16.WAD now retains original wall/sprite texture bytes for
lighting table lookups instead of de-dithering both the input and
the output. Gamma color tables and directly drawn HUD pixel art
still receive an offline RGBI conversion. Replace DOOMT16.WAD.

NEW RGBI LIGHTING PIPELINE:
The WAD now maps original EGA texture-byte codes to their original
VGA source colors, reconstructs 34 Tandy 16-color lighting tables
on the build machine, and keeps the wall/sprite lookup indices.
Matching VGA HUD art is converted directly. No EX CPU overhead.
See RGBI.TXT for matching coverage and fallback details.

REALDOOM-INSPIRED 8086 OPTIMIZATIONS:
The Tandy executables now shortcut integral 16.16 multiplies and
zero-numerator reciprocal division; the 16KB overlapping-wall
column cache has a proper valid bitmap, clean compose scratch,
and a 128-byte height guard. VGA/CGA builds remain unmodified.
BENCH.BAT measures your physical Tandy; DOSBox-X is not 7MHz FPS.

STABLE TANDY GAMEPLAY COLORS:
This release keeps the title screen and HUD RGBI improvements,
but restores original Doom8088 world COLORMAP lighting values,
all gamma tables, and original wall/sprite source texture bytes.
Do not mix older DOOMT16.WAD files with this release.
The previous experimental VGA-derived world color table made
textures overly flat; it is no longer used by normal packaging.

TEXTURES (TANDY ONLY):
DOOM -tandyhi -textures classic   Original world texture baseline
DOOM -tandyhi -textures clean     Conservative wall cleanup test
DOOM -tandy -textures clean       Fast rendering of clean textures
DOOMT16.WAD is Classic; DOOMTC.WAD is Clean; keep both files.
See CLEAN.TXT for actual changed texture names and counts.
